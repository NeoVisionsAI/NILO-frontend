# Panel DEV — simulador de ingestión

Sirve para **probar el mismo flujo que nilo-node** sin cámaras ni dispositivos: datos sintéticos de N segundos por sesión activa.

## Activar

| Entorno | Cómo |
|---------|------|
| `npm run dev` | Visible por defecto (toggle «Simulador ingestión» en ficha paciente) |
| Build producción | `VITE_ENABLE_INGESTION_DEV_PANEL=true` en build + mismo toggle |

La preferencia del toggle se guarda en `localStorage` (`nilo_show_ingestion_dev_panel`).

## Dónde aparece en la UI

1. Entra como **clínico** en el dashboard.
2. Abre un **paciente** (ficha de detalle, no la lista).
3. En la **cabecera**, zona derecha (junto a selector de nodo, Edit y Delete): botón borde naranja **«Simulador ingestión»** (icono `science`).
4. Al pulsarlo, debajo de la cabecera se despliega el panel con los botones de envío.

Si **no ves** el botón: la imagen desplegada en ICASS/GHCR se compiló **sin** la variable (por defecto está apagado). En GitHub: **Settings → Actions → Variables** → `VITE_ENABLE_INGESTION_DEV_PANEL` = `true`, push a `main`, workflow verde, en el host `~/nilo-frontend && ./deploy.sh`.

## Uso

1. Ficha paciente → activar **Monitorización** (sesión activa obligatoria para casi todo).
2. Abrir **Simulador ingestión**.
3. Elegir duración (por defecto 10 s).
4. Pulsar acción → comprobar toast + **Ver resumen** (conteos en `GET /sessions/{id}/overview`).

| Botón | API | Almacenamiento |
|-------|-----|----------------|
| Datos posturales | `POST /landmarks` + PUT + confirm | MinIO + MongoDB |
| Datos fisiológicos | `POST /physiological/bulk` | MongoDB |
| Landmarks faciales | `POST /landmarks` (face_landmarker) | MinIO + MongoDB |
| Nota de texto | `POST …/text-notes` | MongoDB |
| Nota de audio | `POST /audio` + PUT + confirm | MinIO + MongoDB |
| Chunk de vídeo | `POST …/video-segments` + PUT + confirm | MinIO + MongoDB |

Código: `src/dev/ingestion-sim/`, `SessionIngestionDevPanel.tsx`.

## Quitar en producción

No definir `VITE_ENABLE_INGESTION_DEV_PANEL` en la imagen GHCR de producción (el panel no se compila en la UI).
