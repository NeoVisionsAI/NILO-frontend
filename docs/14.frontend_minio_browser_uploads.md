# Subida MinIO desde navegador (nilomed.eu)

## Problema

Página **HTTPS** + `upload_url` **HTTP** a IP interna → **Mixed Content**. El PUT a MinIO se bloquea.

## Solución en frontend

| Flujo | Ruta | Uso |
|-------|------|-----|
| Landmarks (web) | `POST /landmarks/upload` multipart **`landmarks.zip`** → `landmarks.json` dentro | `landmarksService.uploadJsonBatch` (`fflate`, `lib/landmarks-zip.ts`) |
| Audio (web) | `POST /audio/upload` multipart | `audioRecordingService.uploadVoiceNote` |
| Presign | `POST /landmarks` + PUT + confirm | Fallback si `/upload` → 404 (nilo-node / backend antiguo) |

`api.ts` no fuerza `Content-Type: application/json` en `FormData`.

## Reproducción / revisión

`GET /sessions/{id}/media-access?expires_in=86400` — cachear en memoria de la vista; ver `monitoringSessionService.mediaAccess`.

Descargas presignadas siguen necesitando MinIO HTTPS público si el navegador las usa directamente (`docs/MENSAJE_AGENTE_BACKEND_MINIO_HTTPS.md`).

Backend: `NILO-backend/docs/12.clinical_media_access.md`.
