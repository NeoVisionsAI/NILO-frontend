# Landmarks — subida ZIP desde navegador (implementado)

## Flujo

1. Payload JSON clínico (`nilo-mediapipe-face-capture-v1`, `flat-xyz`, …).
2. `buildLandmarksZip` → un fichero `landmarks.json` dentro de `landmarks.zip` (`fflate`).
3. `landmarksService.uploadMultipart` → `POST /landmarks/upload` (FormData).
4. Fallback presign + PUT solo si `/upload` → 404/405 (herramientas antiguas).

## Código

| Pieza | Ruta |
|--------|------|
| ZIP | `src/lib/landmarks-zip.ts` |
| Servicio | `src/services/landmarks.service.ts` |
| Panel DEV | `ingestion-simulator.ts` → `uploadJsonBatch` (pose, face sintético, face real) |

## Errores UI

- **413** — límite nginx / API; ver backend `client_max_body_size`.
- **400** — ZIP sin `.json` con nombre correcto (front siempre usa `landmarks.json`).

Dependencia: `fflate`.
