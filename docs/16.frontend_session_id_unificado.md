# Sesión única (ObjectId) + `capture_kind` landmarks

## Monitorización

- `POST /users/{user_id}/monitoring/start` → `{ user, session }`
- `POST /users/{user_id}/monitoring/stop` → `UserOut`
- No `POST /sessions` + `crypto.randomUUID()` desde toggle ni condata.

`patientMonitoringService` / `patient.service.ts` implementan el lifecycle.

## UI sesión

`ActiveSessionInfo`: mostrar y copiar solo `session.id` (Mongo = MinIO).

## Ingestión

`session_id` = `active_session_id` / `activeMonitoringSession.id` (ObjectId).

## Landmarks

`landmarks.service` multipart: `capture_kind=face` (facial) o `pose` (cuerpo). ZIP con `landmarks.json` dentro.
