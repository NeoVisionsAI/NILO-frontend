# Frontend — descarga de medios clínicos (MinIO)

Alineado con backend desplegado (acceso MinIO para visualización).

## Contrato común

| Paso | Qué hace el front |
|------|-------------------|
| 1 | `GET …/{resource}/download?expires_in=3600` → **JSON** `PresignedDownload` (`download_url`, `expires_in`, opcional `expires_at`) |
| 2 | `fetch(download_url)` en el navegador → bytes (ZIP/JSON/audio/vídeo) |
| 3 | Si falla presign/CORS: `GET …/{resource}/file` con **JWT** → stream vía API |
| 4 | Genérico: `GET /storage/access?kind=…&resource_id=…&expires_in=3600` → mismo JSON presign |

**Importante:** `/download` **no** es el binario. No usar `getBlob('/download')`.

## Landmarks (visualizar malla)

Implementación: `src/lib/fetch-landmarks-document.ts`, `src/services/landmarks.service.ts`.

Orden:

1. `GET /api/v1/landmarks/{id}/download?expires_in=3600` → `fetch(download_url)`
2. `GET /api/v1/landmarks/{id}/file` → `api.getBlob` (JWT)
3. `GET /api/v1/storage/access?kind=landmarks&resource_id={id}&expires_in=3600` → `fetch(download_url)`
4. Fallback: `GET /api/v1/sessions/{sessionId}/media-access?expires_in=…`

Listado previo: `GET /api/v1/landmarks?patient_id=…&session_id=…`.

Fichero: ZIP con `landmarks.json` o JSON directo (`flat-xyz`, frames MediaPipe).

## Audio

- Presign: `GET /api/v1/audio/{id}/download?expires_in=…` → `audioRecordingService.getDownloadUrl`
- Fallback archivo: `GET /api/v1/audio/{id}/file` (pendiente de unificar helper compartido si el backend lo expone igual que landmarks).

## Vídeo / dolor / documentos

Mismos sufijos `/download?expires_in=` y `/file` en sus rutas (ver `docs/12.clinical_media_access.md` en backend o repo API).
