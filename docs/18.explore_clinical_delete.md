# Explorar — borrado de registros clínicos

El front llama **DELETE** (staff). El backend debe eliminar Mongo **y** el objeto en MinIO cuando aplique.

| Recurso | Método | MinIO |
|---------|--------|-------|
| Landmarks (cara/postura) | `DELETE /landmarks/{id}` | `object_key` |
| Audio | `DELETE /audio/{id}` | `object_key` |
| Nota texto | `DELETE /sessions/{session_id}/text-notes/{note_id}` | — |
| Episodio dolor | `DELETE /pain-events/{id}` | `video_object_key`, `landmarks_object_key` |
| Vídeo segmento | `DELETE /sessions/video-segments/{segment_id}` | `object_key` |
| Fisiológico | `DELETE /physiological/{id}` | — |

Respuesta esperada: **204 No Content**.

UI: `ConfirmDialog` — mensaje explícito de irreversibilidad.
